
# Multi-Agent Software Engineering System

基于第一性原理 + 开源复用的轻量化多 Agent 软件工程系统。

## 技术栈

- **调度引擎**: LangGraph
- **多智能体交互**: AutoGen
- **工程流程模板**: MetaGPT
- **代码处理**: Tree-sitter + AST + Ruff
- **测试框架**: Pytest

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行系统

```bash
python -m src.main
```
