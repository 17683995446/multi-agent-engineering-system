## 技术实现说明

### 架构设计

```
UnifiedAtomScanner
├── VariableAtomScanner (变量原子扫描器)
├── MethodAtomScanner (方法原子扫描器)
├── ClassAtomScanner (类原子扫描器)
└── ModuleAtomScanner (模块原子扫描器)
```

### 核心功能

1. **scan_file()**：扫描单个文件，返回四级问题列表
2. **scan_directory()**：批量扫描目录
3. **export_report()**：导出JSON/文本报告
4. **scan_project()**：一站式项目扫描

### 报告结构

```json
{
  "scan_time": "ISO时间戳",
  "total_files": 3,
  "total_issues": 12,
  "issues_by_level": {
    "variable": 10,
    "method": 1,
    "class": 1,
    "module": 0
  },
  "issues": [...],
  "file_stats": {...}
}
```
