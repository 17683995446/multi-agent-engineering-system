## 实施内容

### 1. 新增模块：`src/common/htd_decomposer.py`
这是本阶段的核心模块，包含以下内容：

#### 核心数据结构
- **`HTDTask`**: HTD任务数据类，包含任务ID、名称、描述、类型、层级、父级关系、子任务、依赖关系等
- **`TaskType`**: 任务类型枚举（需求、设计、实现、测试、文档、评审）
- **`TaskStatus`**: 任务状态枚举（待处理、就绪、进行中、已完成、阻塞）
- **`DecompositionStrategy`**: 拆解策略数据类

#### HTD分解器
`HTDDecomposer` 类提供以下功能：
- **多种拆解策略**:
  - `waterfall`: 瀑布式拆解（需求→设计→实现→测试→文档）
  - `standard`: 软件工程标准拆解（分析→设计→实现→测试→评审→文档）
  - `feature`: 功能模块拆解（按功能模块分解）
- **递归分解**: 支持指定最大深度的递归任务分解
- **依赖管理**: 自动建立任务间的依赖关系
- **原子任务识别**: 自动识别和标记原子任务
- **任务查询**: 提供获取原子任务、就绪任务等功能

### 2. 更新模块：`src/agents/requirement_decomposition.py`
增强需求分解Agent，集成HTD分解器：

#### 新增功能

## 功能演示

### 使用示例
```python
from src.agents.requirement_decomposition import RequirementDecompositionAgent

# 初始化Agent
agent = RequirementDecompositionAgent()
agent.start()

# 使用不同策略分解需求
result1 = agent.decompose(
    "开发一个完整的电商购物车系统",
    strategy="standard",
    max_depth=3
)

result2 = agent.decompose(
    "开发一个完整的电商购物车系统",
    strategy="waterfall",
    max_depth=3
)

# 查看结果
print(f"总任务数: {result1['summary']['total_tasks']}")
print(f"原子任务数: {result1['summary']['atomic_count']}")
```
