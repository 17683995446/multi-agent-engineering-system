## 技术实现说明

### HTD层级分解模式

```
Level 1: 顶层需求
  ↓
Level 2: 子需求（分析 / 设计 / 实现 / 测试）
  ↓
Level 3: 子子需求（或直接标记为原子任务）
  ↓
Atomic: 原子任务（不可再分）
```

### 核心方法

1. **decompose()**：主入口，接收需求和最大深度
2. **_decompose_recursive()**：递归分解，复用标准模式
3. **_add_children()**：添加子任务
4. **_flatten_tasks()**：扁平化任务树便于处理
5. **_task_to_dict()**：序列化任务

### 复用原则

- ✅ 复用行业标准的分析-设计-实现-测试四阶段
- ✅ 复用层级分解（Hierarchical Task Decomposition）思路
- ✅ 无自研核心算法，仅封装常用模式
