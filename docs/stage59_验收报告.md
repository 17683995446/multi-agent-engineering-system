## 3. 功能实现详情

### 3.1 ConnectionPool（通用连接池）

- 抽象基类，支持泛型连接类型
- 连接生命周期管理：创建、借用、归还、销毁、验证
- 线程安全（基于Condition实现等待/通知）

### 3.2 PoolConfig（连接池配置）

- max_size: 最大连接数
- min_size: 最小连接数（初始化时创建）
- max_idle_time: 连接最大空闲时间
- connection_timeout: 连接超时
- acquire_timeout: 获取连接超时
- validate_on_borrow/validate_on_return: 借出/归还时验证

### 3.3 PooledConnection（池化连接包装器）

- 包装原始连接，记录元数据
- 跟踪创建时间、最后使用时间、使用次数
- 支持过期判断和有效性验证

### 3.4 核心功能

- **连接复用**：归还的连接重新放入池中
- **上限控制**：达到max_size后获取连接会等待或超时
- **空闲超时**：长时间未使用的连接自动销毁
- **连接验证**：借出时验证连接有效性，失效则重建
- **动态调整**：支持运行时调整连接池大小

### 3.5 pooled（连接池装饰器）

- 自动获取和释放连接
- 简化连接池使用
